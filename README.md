# RoboCon Oxfordshire Operating System Builder

---

This is a Operating System Configuration Tool designed for RoboCon Oxfordshire.

It contains a setup script enabling automated configuration of a standard system.

---
Base OS: Debian Sid

Software Installed: VSCodium, Brave Browser (With Chrome Enterprise Cloud Enrollment)

---

Future Features:

- Installation of OpenUEM/Meshcentral Agent
- Automatically set hostname via last 4 characters of MAC Address
